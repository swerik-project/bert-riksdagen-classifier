\# Scripts for converting doccano annotations to a training data set\## add\_annotation\_remove.pyThe script will take output from a Doccano annotation as JSONL and append it to existing training data. It will also remove the added data added from the unlabeled pool. Just note that it is made for the specific labels, and removes a sentence if any word in it is annotated as "JUNK"The existing training data is a JSON file with word level splits made for a Named Entity Recognition (NER) task for legal references.The structure of the training data is a dictionary like:{&nbsp;
